# The Forest

The Forest is a browser-based 2D slingshot game built with Phaser 3 and TypeScript. It runs in a web browser and does not require Python.

## Run locally

1. Install Node.js 20 or newer.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open the local URL printed by Vite.

Click the title screen to begin. Drag a food projectile back from the slingshot and release to shoot; while it is in flight, hold the mouse button to use that food's special ability. Click the results screen to return to the title.

## Checks

- `npm test` runs focused game-rule tests.
- `npm run build` type-checks and builds the static site into `dist/`.
